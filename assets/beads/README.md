# 实拍珠子素材（待补充）

把每颗天然晶石的**俯视单珠实拍图**放在此目录，渲染器会自动用实拍图替换 SVG 材质。
未提供照片的珠子继续使用 SVG 渲染，可分批补充、互不影响。

## 文件要求

| 项 | 要求 |
| --- | --- |
| 格式 | PNG，**透明背景**，无投影、无道具、无文字/水印 |
| 尺寸 | 1024×1024（最低 768），正方形 |
| 构图 | 珠子正俯视、**正圆**、居中；珠体直径约占画面 **82%**，四周留透明边 |
| 光照 | 柔和棚拍光，主光来自**左上**，右侧补光；避免硬阴影、色偏、反光过曝 |
| 色彩 | 中性校准，接近实物；不要加滤镜/饱和度 |
| 命名 | `{crystalId}.png`，ID 与 `src/data/crystals.js` 一致，例如 `rose-quartz.png`、`silver-obsidian.png` |

可选：同一颗石头可拍 2 张自然差异图，命名 `{id}-a.png` / `{id}-b.png`（变体支持后续加入 manifest）。

## 接入步骤

1. 把照片放入本目录。
2. 在 [`src/data/bead-photos.js`](../../src/data/bead-photos.js) 登记：
   ```js
   export const BEAD_PHOTOS = {
     'rose-quartz': 'rose-quartz.png',
     'silver-obsidian': { src: 'silver-obsidian.png', scale: 1.02 },
   };
   ```
   `scale`/`dx`/`dy` 用于微调构图（一般不需要）。
3. 刷新页面即可；该珠会使用实拍图，其余珠子保持 SVG。渲染器仍负责环视排版、投影、悬停/键盘与分享导出。
4. 若照片边缘有白边/底色，说明去背不干净；若珠体偏小/偏心，用 `scale`、`dx`、`dy` 校正，或在修图时统一裁切。

## 为什么是这个规格

- 环视预览需要每颗珠单独排版（前后遮挡、旋转、换珠），因此必须**单珠**素材；不能直接用整串照片。
- 透明背景 + 无投影，才能让渲染器统一加上纸面投影与接触阴影，保证 24 颗来自不同照片时仍像同一张图。
- 1024 是为了视网膜屏与 2x 预览下仍清晰；珠子在页面中约 40–70 CSS px，1024 已有充足余量。

## 其他用途（非预览）

如果后续要产品详情页/分享 OG 图，建议另拍：
- 整串平铺图（正面/侧面）
- 佩戴图（手部/手腕，自然光）
- 材质微距（可做详情页细节模块）

这些不会进入实时预览，但会用于 PDP 与社交分享。
