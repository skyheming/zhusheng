1. 建议 4:5 竖图，900×1125 以上，主体在画面中部；
2. 覆盖同名文件即可（`order-01.jpg` / `order-02.jpg` / `order-03.jpg`）；
3. 如需改文案/顺序，编辑 [`src/data/story-photos.js`](../../src/data/story-photos.js)；
